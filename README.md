# ImpulsaDev — Landing Page

Landing page oficial de **ImpulsaDev**, estudio de desarrollo web y automatizaciones para negocios pequeños en Santo Domingo, República Dominicana.

🔗 **Sitio en vivo:** [impulsa-dev.vercel.app](https://impulsa-dev.vercel.app/)

## Sobre el proyecto

Sitio de una sola página, construido desde cero con HTML, CSS y JavaScript puro (sin frameworks), pensado como plantilla base reutilizable para futuros clientes del estudio.

## Stack

- HTML5 semántico
- CSS3 (variables/custom properties, Grid, Flexbox, animaciones con `@keyframes`)
- JavaScript vanilla (`IntersectionObserver` para animaciones on-scroll, generación dinámica de links de WhatsApp)
- Tipografías: [Space Grotesk](https://fonts.google.com/specimen/Space+Grotesk) + [Inter](https://fonts.google.com/specimen/Inter)
- Desplegado en [Vercel](https://vercel.com)

## Correr el proyecto localmente

No requiere instalación de dependencias. Basta con abrir `index.html` en el navegador, o servirlo con una extensión tipo Live Server para recarga automática al editar.
